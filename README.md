# EV SmartCharge ⚡

Smart EV Charging & Route Finder.

## Features

- EV Battery Dashboard
- Charging Station Finder
- Charging Cost Calculator
- Charging Time Calculator
- Responsive UI
- Dark/Light Mode
- Node.js Backend
- REST API
- Docker
- Jenkins CI/CD
- GitHub

## Technologies

HTML
CSS
JavaScript
Node.js
Express
Docker
Jenkins
Git
GitHub

## Run Frontend

Open frontend/index.html in browser.

## Run Backend

cd backend

npm install

npm start

Backend:
http://localhost:5000

## Docker

docker compose up -d --build

Frontend:
http://localhost:8080

Backend:
http://localhost:5000
